# Admin specifications

Đặt ở đây các đặc tả về admin route, role/permission, dashboard widget, table/filter/pagination, form và acceptance criteria cho admin frontend.

Mỗi spec cần ghi rõ status, actor, permission, main flow, edge cases và tiêu chí nghiệm thu. Tài liệu triển khai tương ứng nằm trong docs/admin/.
