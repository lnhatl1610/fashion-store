# Storefront specifications

Đặt ở đây các đặc tả về browse catalog, product detail, auth, cart, checkout, account, responsive behavior, SEO và performance.

Mỗi spec cần ghi rõ user flow, dữ liệu/API phụ thuộc, trạng thái loading/empty/error và acceptance criteria. Tài liệu triển khai tương ứng nằm trong docs/storefront/.
